# Spacing & density

Spacing uses a named scale from `--spacing-none` to `--spacing-5xl`. The **density** theme axis tightens padding in containers and controls for data-heavy screens: **comfortable** (default) or **compact**.

## What changes with density

These component tokens differ between comfortable and compact; everything else stays the same.

## Guidelines

- Space related items closer together than unrelated ones, e.g. `--spacing-xs` inside a group and `--spacing-lg` between groups.
- Use compact density for tables, dashboards and admin tools; comfortable for forms, marketing and reading.
- Don't mix densities on one screen; set it once on the theme scope.
