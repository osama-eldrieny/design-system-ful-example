# Examples

Complete screens built only from `@ds/react` components and tokens. They open outside the docs; the theme you pick in the playground applies to all of them.

| Example | What it shows |
| --- | --- |
| <a href="prototypes/#/landing" target="_top">Store landing page</a> | Navbar, filters that work (search, categories, price, sort), product grid with pagination, plan picker, newsletter form with a toast |
| <a href="prototypes/#/dashboard" target="_top">Analytics dashboard</a> | Stats, a sortable metrics table in tabs, system status, settings, team list and integrations |
| <a href="prototypes/#/demo" target="_top">Theme playground</a> | Switch brand, mode, language, typeface, density, radius and shadow, and copy the attributes for your app |
