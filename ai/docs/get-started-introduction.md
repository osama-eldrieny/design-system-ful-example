# Panda Design System

Panda is a themeable, accessible React component library and the design tokens behind it. One codebase serves three brands (Diamond, Amber, Opal), light and dark mode, English and Arabic, two densities, three corner styles and four shadow levels.

**Code is the source of truth.** Tokens are plain CSS, the components are the React library, and these docs render the real components, so what you see here is exactly what ships.

## Try any theme

The toolbar at the top switches every example on every page between themes: brand, mode, language, typeface, density, radius and shadow. Component pages also have a **Preview theme** bar. The docs themselves keep a neutral look, so only the examples change. Examples start in the default theme: **Diamond, light, English, sans-serif, comfortable, round, flat**.

## Quality bar

- WCAG 2.2 AA: contrast is checked in every brand and mode on every build, and every example runs through axe.
- Every component is styled only by its own tokens; a lint rule rejects raw colors and sizes.
- Every example in these docs is also a test that runs in a real browser.
