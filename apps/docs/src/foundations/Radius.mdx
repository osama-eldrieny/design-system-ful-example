# Radius

The **radius** theme axis sets how rounded the interface feels: **square** for sharp, technical products, **round** (default) for friendly, soft corners, **pills** for fully rounded controls.

## Guidelines

- Nested corners look right when the inner radius is the outer radius minus the padding between them.
- Keep one radius theme per product; it is part of the brand's character.
